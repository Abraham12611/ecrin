# 11 — Demo, submission and official references

## Suggested 60–90 second showcase

1. **0–8s / Establish the object:** close shot of ÉCRIN default Voyage, real video playing, working transport controls. No slideshow.
2. **8–18s / Signature detail:** drag Voyage zipper volume and show real volume percentage; toggle mute independently.
3. **18–30s / The reveal:** open Settings → Appearance → Skin, show five clear choices and current active selection.
4. **30–50s / Five variants:** move Voyage → Bridle (buckle seek) → Horlogerie (crown volume) → Folio (fold-out menu) → Grand Tourer (illuminated rail). Never stop the video. Maintain visible time throughout.
5. **50–67s / Proof of craft:** show responsive mobile form, keyboard focus, a menu in compact layout, reduced-motion option, and real fullscreen.
6. **67–85s / Close:** return to Voyage, present elegant `ÉCRIN — The art of playback` and short one-line design statement. Show public URL.

Avoid claiming all five are “AI-generated” instead of engineered; AI helps create art assets but the functional components are real code. Avoid logo/brand affiliation claims.

## Suggested submission description

> ÉCRIN is an original family of five craft-inspired Video.js v10 skins. A single player moves between travel-case leatherwork, equestrian saddlery, watchmaking, fine folios, and grand-touring interiors through an in-player Appearance menu. Each skin has a signature tactile control—zipper, buckle, crown, fold, or illuminated rail—while playback, keyboard accessibility, mobile usability, and media state remain continuous. The aim is to bring the care of luxury object design to everyday video interaction.
